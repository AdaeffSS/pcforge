# PCForge — подбор комплектующих для компьютера

Учебный проект по дисциплине «Введение в интернет-технологии» (БГТУ «ВОЕНМЕХ»).
Автор: Адаев Степан Сергеевич, группа Н251Б. **Вариант 1** — подбор комплектующих
для компьютера: сборка конфигурации из нескольких частей и подсчёт итоговой стоимости.

## Как запустить
Откройте `frontend/index.html` в браузере (сервер не нужен). Для курсов валют нужен интернет.
