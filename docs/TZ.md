# Техническое задание — PCForge

**Вариант 1.** Подбор комплектующих для компьютера.
**Особенность варианта:** сборка конфигурации из нескольких частей и подсчёт итоговой стоимости.

## Назначение
PCForge помогает пользователю без опыта собрать компьютер: выбрать комплектующие
из каталога, сложить их в сборку, увидеть итоговую цену и предупреждения о
несовместимости (сокет, тип памяти, форм-фактор, длина видеокарты, мощность БП).

## Страницы
| Страница | Файл | Содержимое | Что может пользователь |
|---|---|---|---|
| Главная | `index.html` | назначение сайта, шаги «как это работает», подборка из 6 популярных позиций | перейти в каталог, в сборку, на страницу товара |
| Каталог | `catalog.html` | все комплектующие (не менее 12, сейчас 30), панель фильтров (категория, бренд, цена, поиск) и сортировка | найти и отфильтровать позиции, добавить в сборку |
| Товар | `product.html` | изображение, описание, таблица характеристик, цена, блок совместимости | добавить товар в сборку, увидеть цену в валюте |
| Моя сборка | `build.html` | 8 слотов (CPU, плата, ОЗУ, видеокарта, накопитель, БП, корпус, охлаждение), итоговая сумма, потребление, проверки совместимости | убрать позицию, очистить сборку, сохранить в кабинете |
| Контакты | `contacts.html` | адрес, телефон, почта, режим работы, слоган, форма обратной связи | отправить вопрос |
| О проекте | `about.html` | описание проекта и автора | — |
| Ошибка 404 | `404.html` | сообщение и ссылки на главную и каталог | вернуться на сайт |

Меню в шапке присутствует на всех страницах и ведёт на все страницы сайта.

## Связи между страницами
Главная → Каталог → Товар → Моя сборка; любая страница → меню → любая страница.

## Этапы
- ПР 1 — статическая вёрстка (HTML, CSS), данные в разметке.
- ПР 2 — фильтры, сортировка, сборка без перезагрузки, проверка форм, курсы валют ЦБ РФ.
- ПР 3 — сервер FastAPI, база SQLite, регистрация и вход, сохранение сборок.
- ПР 4 — Docker, размещение на https://it.adaeff.ru.
